# Software Build, Linking, and Code Security

Coursework exploring software build and linking concepts, runtime instrumentation, and code-security analysis.

## Overview
The reports cover several software-engineering exercises: observing or intercepting function calls in a controlled lab, examining static and dynamic linking and shared libraries, and comparing static application security testing (SAST) with software composition analysis (SCA).

This repository is a collection of coursework reports rather than a single software product.

## Topics covered
- Function-call instrumentation in a controlled environment
- Static and dynamic linking
- Shared-library concepts
- Static application security testing (SAST)
- Software composition analysis (SCA)
- Comparison of code-security analysis approaches

## Technologies and concepts
Build and linking fundamentals, shared libraries, runtime instrumentation, SAST, SCA. Specific tools and commands should be added only after confirming them against the individual reports or source files.

## Repository contents and limitations
The repository currently contains three DOCX reports and does not include a standalone source tree or a reproducible CI/CD pipeline. Therefore, this README does not claim that a working pipeline or automated quality checks are already implemented.

## Reproducing the work
To make the exercises reproducible, add reviewed source files, environment/tool versions, exact build commands, and sample outputs for each exercise. Keep instrumentation limited to systems and software you are authorized to test.
