# Software Build Systems and Code Security

Software-engineering coursework covering process instrumentation, static and dynamic linking, shared libraries, and comparative SAST/SCA tool analysis.

## Overview

The reports describe three areas: instrumentation of a running process to observe or intercept function calls in a controlled lab, the compiler/linker pipeline and shared libraries, and a comparative review of static application security testing (SAST) and software composition analysis (SCA) tools.

## Topics and Features

- Understanding compilation, linking, and dynamic libraries
- Building and inspecting programs with static and dynamic linking
- Review of build automation and integration/testing workflows
- Comparison of SAST and SCA approaches and tools
- Controlled process-instrumentation concepts, as described in the report

## Technologies

C/C++ and Linux build tooling (as relevant to the reports), compilers, linkers, shared libraries, SAST, SCA

## Project Context

This is an educational portfolio project based on university coursework. The README summarizes what is supported by the accompanying coursework reports; it does not imply that every listed topic is implemented in a production-ready system.
